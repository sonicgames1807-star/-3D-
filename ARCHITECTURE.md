# Архитектура и план MVP

## Кратко

Mesh Scan Studio — локальный инструмент для новичка, чтобы осмотреть скан, сгладить шум, обработать область кистью, уменьшить число полигонов и экспортировать копию.

## Границы первой версии

| Готово в MVP | Позже | Не входит в MVP |
|---|---|---|
| STL/OBJ/PLY (включая облака точек)/OFF/glTF/GLB, просмотр WebGL 2, статистика и открытые рёбра | FBX/3MF через зрелый проверенный конвертер, история проекта на диске, диагностический отчёт, улучшенные алгоритмы упрощения | облачная обработка, восстановление отсутствующей геометрии ИИ |
| Taubin-подобное сглаживание и защита открытых границ | preview до применения, маска защиты, выбор компонента | безусловное закрытие отверстий, CAD и ретопология |
| кистевое сглаживание с радиусом и falloff | worker для кистевых мазков, геодезическая маска | профессиональная гарантия «готово к печати» |
| кластерное упрощение, сравнение, отмена/повтор, экспорт копии | установщик/portable-сборка, материалы OBJ/glTF и цветовые атрибуты PLY | телеметрия, учётная запись, загрузка файлов в сеть |

## Модули

- `index.html`, `styles.css` — русский интерфейс.
- `app.js` — состояние документа, история, команды UI, импорт/экспорт.
- `viewer.js` — WebGL 2, orbit/pan/zoom, wireframe, сетка и hit-test лучом.
- `mesh-core.js` — STL/OBJ/PLY (включая облака точек)/OFF/glTF/GLB парсеры, диагностика, сглаживание, кисть, кластеризация, экспорт STL/OBJ/PLY.
- `mesh-worker.js` — фоновое сглаживание/упрощение; отмена через безопасное завершение worker, рабочий документ не меняется.
- `tests/test_mesh.mjs` — проверки численных свойств.

## Ограничения и риски

Кластеризация не гарантирует заданное число полигонов и может менять контур. Taubin-подобное сглаживание не отделяет шум по амплитуде/частоте и не сохраняет все мелкие детали. Кисть обрабатывает вершины в пространственном радиусе около лучевого попадания; ограничение обратной поверхности приближённое по направлению луча. Кистевые мазки выполняются в основном потоке. История ограничена 8 операциями, не записывается на диск. Максимум импорта — 150 000 треугольников. UI протестирован в Chromium; сборка установщика Windows не выполнялась.

## Проверки

Запуск: `node tests/test_mesh.mjs` или `test.bat`. Проверяются ASCII/binary STL, OBJ с многоугольником, экспорт/повторный импорт, снижение численной локальной шероховатости, ограниченное изменение габаритов, кистевой falloff, защита границ, приближение к цели упрощения и отказ от нечисловых OBJ-вершин. Дополнительно вручную проверены демонстрационная модель, UI-импорт OBJ, фоновые операции, отмена/повтор и отсутствие ошибок консоли в Chromium.

Сборка установщика не включена: текущая поставка — исходники автономного веб-приложения без сторонних библиотек. Запуск требует Python для локального HTTP-сервера и браузер с WebGL 2.
